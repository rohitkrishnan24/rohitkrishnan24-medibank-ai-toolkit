# Chart and Visualisation Adviser

## Purpose
Recommend the most appropriate chart type and build it with professional Medibank teal formatting.

## Before you begin
- Confirm what question the chart should answer
- Confirm the audience
- Confirm whether output will be used in Excel, PowerPoint, or Word

## Workflow

### Step 1 - Analyse data structure
Identify number of data series, data points per series, whether x axis represents time or categories, and whether the goal is comparison, trend, composition, or distribution.

### Step 2 - Recommend chart type
Trend over time with 4 or more periods: Line chart. Comparison across fewer than 8 categories: Clustered bar. Comparison across 8 or more categories: Horizontal bar. Part to whole: Stacked bar not pie. Distribution: Histogram. Two metrics: Scatter plot. Explain recommendation in one sentence.

### Step 3 - Build the chart
Create the chart with Medibank formatting: primary colour hex 006D6D, white background, descriptive title with metric and time period, remove gridlines except horizontal, data labels on final data point only, legend below chart, Calibri 11pt for labels.

### Step 4 - Add insight annotation
Add one line below the chart title stating the key insight with the specific number.

### Step 5 - Position the chart
Place chart below or to the right of the source data without overlapping cells.

## Output
- Chart with Medibank teal formatting
- Descriptive title and key insight annotation
- Chart type justification in one sentence

## Common pitfalls
- Do not use pie charts for more than 4 categories
- Do not use 3D chart effects
- Do not leave the default Chart Title placeholder
- Do not include more than 5 data series in one chart
